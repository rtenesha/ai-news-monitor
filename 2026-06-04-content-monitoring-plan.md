## Проект

**Система автоматического мониторинга ИИ-новостей**

Настроить агрегатор, который собирает новости из всех текущих источников в одном месте и фильтрует их по релевантности. Вместо 1–2 часов ручного просмотра — 15–20 минут в день на готовую подборку.

### Для кого
Для себя как контент-менеджера Zerocoder. Результат оформляется как кейс, применимый для других CMов и редакторов Telegram-каналов по теме ИИ.

### Сценарий работы
Каждое утро открываю Feedly — вижу отфильтрованные материалы за прошедшие сутки. Отмечаю подходящее, остальное игнорирую. Из отмеченного беру темы для контент-плана или передаю в работу.

### Как проверю результат
- Время на мониторинг сократилось до 15–20 минут в день (фиксирую первые две недели)
- Не пропускаю ни один значимый инфоповод по теме ИИ и no-code
- Через 30 дней есть готовый документ с описанием системы, скриншоты, до/после

### Как буду презентовать
Документ с описанием системы + скриншоты интерфейса + данные о времени до и после. Формат: мини-кейс «Как я сократила время на мониторинг новостей в 4 раза».

## Первое действие — выполнено 4 июня 2026

### Шаг 1. Регистрация в Feedly
1. Открыть feedly.com
2. Нажать «Get started for free»
3. Зарегистрироваться через Google-аккаунт

### Шаг 2. Добавить веб-источники
В Feedly нажать «+ Add content» → вставить URL поочерёдно:
- `https://ya.zerocoder.ru/`
- `https://www.zdnet.com/`
- `https://www.forbes.com/ai/`

Feedly сам найдёт RSS-ленту и предложит подписаться.

### Шаг 3. Конвертировать Telegram-каналы
1. Открыть rss.app
2. Нажать «Create feed» → вставить ссылку на канал, например `https://t.me/neuraldvig`
3. Скопировать полученную RSS-ссылку
4. Вставить её в Feedly через «+ Add content»
5. Повторить для каждого канала

### Шаг 4. Создать папки
В Feedly: правая панель → «New feed group» → назвать «ИИ-новости». Перетащить источники в папку.

### Скриншоты для домашки
- Feedly с подключёнными источниками (все 7 в списке)
- Пример дайджеста за первый день
- rss.app с конвертированными Telegram-каналами
